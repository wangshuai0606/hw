这是一个基本的 LaTeX 文档示例，展示了文档的基本结构。

\section{文档结构}
LaTeX 文档由以下部分组成：
\begin{itemize}
    \item 导言区：设置文档类型、宏包、标题等
    \item 正文区：包含所有章节和内容
\end{itemize}

\subsection{常用命令}
\begin{enumerate}
    \item \textbackslash section\{\} -- 一级标题
    \item \textbackslash subsection\{\} -- 二级标题
    \item \textbackslash textbf\{\} -- 加粗
    \item \textbackslash textit\{\} -- 斜体
\end{enumerate}

\section{总结}
LaTeX 是一种强大的排版工具，适合撰写学术论文和科技文档。
